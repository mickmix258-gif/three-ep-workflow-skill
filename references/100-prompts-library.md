# คลังคำสั่งยอดนิยม 100 คำสั่ง (100 Prompts Library) แยกตาม 10 หมวดหมู่

รวบรวมคำสั่งยอดนิยมที่แมปเข้ากับ Framework 3 EPs และสถาปัตยกรรม 5 ชั้น เพื่อให้สามารถเรียกใช้ได้ทันที

---

## หมวด 1: Writing / งานเขียนและตรวจทาน (1–10) -> [EP1: Co-Worker]
1. `Write a professional email to [person] about [topic].` — เขียนอีเมลอย่างมืออาชีพถึง [บุคคล] เกี่ยวกับ [หัวข้อ]
2. `Rewrite this text to make it more formal/informal.` — เขียนข้อความนี้ใหม่ให้มีความเป็นทางการ/ไม่เป็นทางการมากขึ้น
3. `Proofread and correct grammar mistakes in this text.` — ตรวจทานและแก้ไขข้อผิดพลาดทางไวยากรณ์ในข้อความนี้
4. `Draft a compelling cover letter for a job application.` — ร่างจดหมายสมัครงาน (Cover Letter) ที่น่าสนใจสำหรับตำแหน่งงาน
5. `Turn these bullet points into a well-structured paragraph.` — แปลงหัวข้อย่อยเหล่านี้ให้เป็นย่อหน้าที่เรียบเรียงอย่างเป็นระบบ
6. `Make this text shorter without losing key meaning.` — ย่อข้อความนี้ให้สั้นลงโดยไม่สูญเสียใจความสำคัญ
7. `Expand this outline into a full article with examples.` — ขยายโครงร่างนี้ให้เป็นบทความฉบับสมบูรณ์พร้อมตัวอย่างประกอบ
8. `Rewrite this message in a [specific brand/role] tone of voice.` — ปรับแก้ข้อความนี้ให้ตรงกับน้ำเสียงของ [แบรนด์/บทบาทที่ระบุ]
9. `Fix punctuation, spelling, and capitalization errors.` — แก้ไขเครื่องหมายวรรคตอน การสะกดคำ และการใช้อักษรพิมพ์ใหญ่
10. `Create a professional bio for my LinkedIn profile.` — เขียนประวัติย่อแบบมืออาชีพสำหรับโปรไฟล์ LinkedIn

## หมวด 2: Creative Writing & Storytelling / งานสร้างสรรค์ (11–20) -> [EP3: Build]
11. `Write a short story about [character] who [action].` — เขียนเรื่องสั้นเกี่ยวกับ [ตัวละคร] ที่กำลังทำ [การกระทำ]
12. `Create a poem about [topic] in the style of [poet].` — แต่งบทกวีเกี่ยวกับ [หัวข้อ] ในสไตล์ของ [กวีที่ระบุ]
13. `Write a creative dialogue between [person A] and [person B].` — เขียนบทสนทนาเชิงสร้างสรรค์ระหว่าง [บุคคล A] และ [บุคคล B]
14. `Describe a scene of [event] using sensory details.` — บรรยายฉากของ [เหตุการณ์] โดยใช้รายละเอียดประสาทสัมผัสทั้งห้า
15. `Draft a children's bedtime story teaching [lesson].` — ร่างนิทานก่อนนอนสำหรับเด็กที่สอดแทรกคติสอนใจเรื่อง [บทเรียน]
16. `Write a satirical news article about [trend/topic].` — เขียนบทความข่าวเชิงเสียดสีเกี่ยวกับ [กระแส/หัวข้อ]
17. `Generate a dramatic monologue from the perspective of [character].` — เขียนบทพูดคนเดียว (Monologue) แสดงอารมณ์ลึกซึ้งจากมุมมองของ [ตัวละคร]
18. `Create an unexpected plot twist for a story about [premise].` — คิดจุดหักมุมของเรื่อง (Plot Twist) ที่คาดไม่ถึงสำหรับพล็อตเกี่ยวกับ [โครงเรื่อง]
19. `Describe a futuristic sci-fi world set in [year/environment].` — พรรณนาโลกไซไฟแห่งอนาคตที่เกิดขึ้นในปี [ปี/สภาพแวดล้อม]
20. `Write a haiku capturing the essence of [season/emotion].` — เขียนบทกวีไฮกุที่สะท้อนหัวใจสำคัญของ [ฤดูกาล/อารมณ์]

## หมวด 3: Coding & Tech / งานพัฒนาโค้ดและเทคนิค (21–30) -> [EP3: Build]
21. `Debug this code and explain the root cause of the error.` — ตรวจหาจุดผิดพลาดในโค้ดนี้และอธิบายสาเหตุที่แท้จริง
22. `Write a Python function to [task] with unit tests.` — เขียนฟังก์ชันภาษา Python เพื่อทำ [งานที่ระบุ] พร้อมเขียน Unit Tests
23. `Optimize this SQL query for better query performance.` — ปรับปรุงคำสั่ง SQL นี้ให้ประมวลผลได้เร็วและมีประสิทธิภาพยิ่งขึ้น
24. `Refactor this code following clean architecture principles.` — ปรับปรุงโครงสร้างโค้ดตามหลัก Clean Architecture
25. `Convert this code from [language A] to [language B].` — แปลงโค้ดนี้จาก [ภาษา A] ไปเป็น [ภาษา B]
26. `Create a database schema for an application handling [domain].` — ออกแบบ Database Schema สำหรับแอปพลิเคชันที่จัดการงาน [ด้านที่ระบุ]
27. `Design a RESTful API endpoint specification for [service].` — ออกแบบข้อกำหนด RESTful API Endpoints สำหรับ [บริการ]
28. `Write comprehensive unit tests covering edge cases for [function].` — เขียน Unit Tests ที่ครอบคลุมกรณีขอบเขต (Edge Cases) สำหรับ [ฟังก์ชัน]
29. `Explain the time and space complexity (Big O) of this algorithm.` — อธิบายความซับซ้อนด้านเวลาและพื้นที่ (Big O Complexity) ของอัลกอริทึมนี้
30. `Create a regex pattern to match and validate [pattern].` — สร้างนิพจน์ปกติ (Regex) เพื่อจับคู่และตรวจสอบ [รูปแบบข้อมูล]

## หมวด 4: Analysis & Research / การวิเคราะห์และการวิจัย (31–40) -> [EP2: Context]
31. `Conduct a SWOT analysis for [company/product].` — ทำการวิเคราะห์ SWOT Analysis สำหรับ [บริษัท/ผลิตภัณฑ์]
32. `Summarize this research article in 5 key takeaways.` — สรุปบทความวิจัยนี้ให้เหลือข้อค้นพบสำคัญ 5 ประการ
33. `Compare and contrast [Option A] and [Option B] across key metrics.` — เปรียบเทียบจุดเหมือนและจุดต่างระหว่าง [ทางเลือก A] กับ [ทางเลือก B]
34. `Identify potential risks, assumptions, and mitigations for [project].` — ระบุความเสี่ยง สมมติฐาน และแนวทางป้องกันสำหรับ [โครงการ]
35. `Analyze the pros and cons of adopting [technology/strategy].` — วิเคราะห์ข้อดีและข้อเสียของการนำ [เทคโนโลยี/กลยุทธ์] มาปรับใช้
36. `Break down this complex financial concept into layman's terms.` — อธิบายแนวคิดทางการเงินที่ซับซ้อนนี้ให้เข้าใจง่ายเหมือนคนทั่วไป
37. `Evaluate the competitive advantages and moats of [business].` — ประเมินความได้เปรียบทางการแข่งขัน (Moats) ของ [ธุรกิจ]
38. `Synthesize findings from multiple survey data points.` — สังเคราะห์ผลลัพธ์จากข้อมูลแบบสำรวจหลายชุดเข้าด้วยกัน
39. `Identify key industry trends shaping [market/sector] in the next 3 years.` — ชี้แนวโน้มสำคัญที่จะขับเคลื่อน [อุตสาหกรรม/ตลาด] ในอีก 3 ปีข้างหน้า
40. `Create an evaluation rubric with weighted scoring for [decision].` — สร้างตารางประเมิน Rubric พร้อมน้ำหนักคะแนนสำหรับการตัดสินใจ [เรื่องที่ระบุ]

## หมวด 5: Business & Marketing / แผนธุรกิจและการตลาด (41–50) -> [EP2 & EP3]
41. `Draft a comprehensive business plan for a startup in [industry].` — ร่างแผนธุรกิจฉบับสมบูรณ์สำหรับสตาร์ทอัพใน [อุตสาหกรรม]
42. `Design a multi-channel marketing campaign strategy for [product].` — ออกแบบกลยุทธ์แคมเปญการตลาดหลายช่องทางสำหรับ [ผลิตภัณฑ์]
43. `Write an elevator pitch for [product/service] in under 60 seconds.` — เขียน Elevator Pitch สำหรับ [ผลิตภัณฑ์/บริการ] ให้นำเสนอจบใน 60 วินาที
44. `Create a 30-60-90 day onboarding and launch plan for [initiative].` — จัดทำแผนงาน 30-60-90 วัน สำหรับการเปิดตัว [โครงการริเริ่ม]
45. `Generate 10 catchy brand slogans and value propositions.` — คิดสโลแกนและ Value Proposition ที่น่าจดจำ 10 แบบ
46. `Draft a customer retention email sequence to reduce churn.` — ร่างชุดอีเมลรักษาฐานลูกค้าเพื่อลดอัตราการยกเลิกใช้งาน (Churn)
47. `Perform a customer persona breakdown for [target segment].` — จัดทำ Customer Persona สำหรับกลุ่มลูกค้าเป้าหมาย [กลุ่มที่ระบุ]
48. `Develop a pricing strategy model comparing subscription vs one-time.` — ออกแบบโมเดลกลยุทธ์การตั้งราคาเปรียบเทียบแบบบอกรับสมาชิกกับซื้อขาด
49. `Write a press release announcing the launch of [new feature].` — เขียนข่าวแจกประชาสัมพันธ์ (Press Release) ประกาศเปิดตัว [ฟีเจอร์ใหม่]
50. `Formulate a go-to-market (GTM) playbook for expanding into [region].` — จัดทำ GTM Playbook สำหรับการขยายธุรกิจเข้าสู่ [ภูมิภาคใหม่]

## หมวด 6: Education & Explanation / การศึกษาและการอธิบาย (51–60) -> [EP2: Context]
51. `Explain [complex topic] to a 5-year-old child.` — อธิบาย [เรื่องซับซ้อน] ให้เด็ก 5 ขวบเข้าใจได้ง่าย
52. `Create a structured 4-week self-study curriculum for [subject].` — จัดทำหลักสูตรการเรียนรู้ด้วยตนเอง 4 สัปดาห์สำหรับวิชา [วิชาที่ระบุ]
53. `Give 3 real-world analogies to explain how [system] works.` — ยก 3 อุปมาอุปไมยในชีวิตจริงเพื่ออธิบายกลไกการทำงานของ [ระบบ]
54. `Design a quiz with 5 multiple-choice questions testing [concept].` — ออกแบบแบบทดสอบปรนัย 5 ข้อเพื่อวัดความเข้าใจใน [แนวคิด]
55. `Explain the fundamental difference between [Concept A] and [Concept B].` — อธิบายความแตกต่างพื้นฐานระหว่าง [แนวคิด A] กับ [แนวคิด B]
56. `Teach me [subject] step-by-step with interactive checkpoints.` — สอนวิชา [วิชาที่ระบุ] แบบทีละขั้นพร้อมจุดตรวจความเข้าใจ
57. `Break down the historical causes leading to [historical event].` — สรุปสาเหตุทางประวัติศาสตร์ที่นำไปสู่ [เหตุการณ์สำคัญ]
58. `Provide a cheat-sheet of essential formulas and definitions for [field].` — จัดทำสูตรสรุป (Cheat-sheet) และนิยามสำคัญสำหรับ [สาขาความรู้]
59. `Draft an outline for an educational workshop on [skill].` — ร่างโครงสร้างหลักสูตรเวิร์กช็อปเชิงปฏิบัติการสำหรับ [ทักษะ]
60. `Create flashcard pairs (Question & Answer) for studying [topic].` — สร้างชุดคำถาม-คำตอบแบบแฟลชการ์ดสำหรับทบทวน [หัวข้อ]

## หมวด 7: Translation & Localization / การแปลและการปรับภาษา (61–70) -> [EP1: Co-Worker]
61. `Translate this document into professional business Thai.` — แปลเอกสารนี้เป็นภาษาไทยทางการสำหรับธุรกิจ
62. `Localize this marketing copy to fit Thai cultural nuances.` — ปรับสำนวนการตลาดให้เข้ากับบริบททางวัฒนธรรมไทย
63. `Translate this technical specification preserving exact terms.` — แปลเอกสารข้อกำหนดทางเทคนิคโดยรักษาคำศัพท์เฉพาะทางอย่างถูกต้อง
64. `Provide 3 natural-sounding alternative translations for [phrase].` — ให้คำแปลทางเลือกที่ลื่นไหลเป็นธรรมชาติ 3 แบบสำหรับ [วลี]
65. `Translate and adapt this software UI text within length constraints.` — แปลและปรับข้อความ UI ของซอฟต์แวร์โดยจำกัดความยาวตามหน้าจอ
66. `Explain the cultural context and background behind this idiom.` — อธิบายบริบททางวัฒนธรรมและที่มาเบื้องหลังสำนวนนี้
67. `Translate this formal legal disclaimer into standard Thai terms.` — แปลข้อความปฏิเสธความรับผิดชอบทางกฎหมายเป็นภาษาไทยมาตรฐาน
68. `Check this translated text for accuracy, tone, and consistency.` — ตรวจสอบข้อความที่แปลแล้วด้านความถูกต้อง น้ำเสียง และความสม่ำเสมอ
69. `Translate this conversational transcript into natural spoken Thai.` — แปลบทสนทนานี้เป็นภาษาไทยพูดที่เป็นธรรมชาติ
70. `Find the closest Thai idiomatic equivalents for these English idioms.` — ค้นหาสำนวนไทยที่เทียบเท่ากับสำนวนภาษาอังกฤษเหล่านี้

## หมวด 8: Brainstorming & Ideation / การระดมสมอง (71–80) -> [EP3: Build]
71. `Brainstorm 10 creative ideas for [topic/goal].` — ระดมสมองคิด 10 ไอเดียสร้างสรรค์สำหรับ [เป้าหมาย/หัวข้อ]
72. `Propose unconventional solutions to solve [problem].` — เสนอแนวทางแก้ไขที่แปลกใหม่นอกกรอบสำหรับ [ปัญหา]
73. `What would [famous company/innovator] do to address [challenge]?` — หากเป็น [บริษัทนวัตกรรม/บุคคลสำคัญ] จะแก้ [ความท้าทายนี้] อย่างไร?
74. `Brainstorm potential side-project ideas combining [Domain A] and [Domain B].` — คิดไอเดียโปรเจกต์เสริมที่ผสมผสานระหว่าง [ด้าน A] กับ [ด้าน B]
75. `Identify untapped market opportunities within [industry].` — ชี้โอกาสทางการตลาดที่ยังไม่มีใครเจาะใน [อุตสาหกรรม]
76. `Generate 5 bold hypotheses to disrupt traditional [business model].` — ตั้งสมมติฐานที่ท้าทาย 5 ข้อเพื่อพลิกโฉมโมเดลธุรกิจแบบเดิม
77. `Brainstorm ideas for improving user onboarding retention.` — ระดมความคิดเพื่อพัฒนาขั้นตอนการเริ่มต้นใช้งานของผู้ใช้ใหม่ให้ไม่หลุด
78. `Suggest innovative feature extensions for an existing [app].` — เสนอฟีเจอร์ต่อยอดที่น่าสนใจสำหรับ [แอปพลิเคชันที่มีอยู่เดิม]
79. `Conduct a SCAMPER brainstorming session on [product].` — ดำเนินการระดมสมองด้วยเทคนิค SCAMPER กับ [ผลิตภัณฑ์]
80. `List 10 potential experiment ideas to test [growth metric].` — ทำรายการไอเดียการทดลอง 10 อย่างเพื่อทดสอบการเติบโตของ [ตัวชี้วัด]

## หมวด 9: Roleplay & Persona / การจำลองบทบาทเชิงลึก (81–90) -> [EP3: Build]
81. `Act as a senior software architect and critique this design.` — สวมบทบาทเป็นสถาปนิกซอฟต์แวร์อาวุโสและวิจารณ์การออกแบบนี้
82. `Pretend you are a skeptical investor questioning my pitch.` — สวมบทบาทเป็นนักลงทุนที่สงสัยและตั้งคำถามท้าทายแผนงาน
83. `Be my executive leadership coach and guide me through [dilemma].` — สวมบทเป็นโค้ชผู้บริหารและชี้แนะวิธีจัดการ [ภาวะกลืนไม่เข้าคายไม่ออก]
84. `Simulate a realistic job interview for the position of [job title].` — จำลองการสัมภาษณ์งานเสมือนจริงสำหรับตำแหน่ง [ชื่อตำแหน่ง]
85. `Act as a customer support specialist handling an upset client.` — สวมบทบาทเป็นเจ้าหน้าที่บริการลูกค้าที่รับมือกับลูกค้าร้องเรียน
86. `Roleplay as a Socratic tutor questioning my assumptions.` — สวมบทเป็นผู้สอนตามแนวทางโสกราตีส (Socratic) ถามคำถามเพื่อเปิดมุมมอง
87. `Pretend you are a cybersecurity auditor reviewing my system.` — สวมบทบาทเป็นผู้ตรวจสอบความปลอดภัยไซเบอร์ประเมินระบบ
88. `Act as a seasoned product manager prioritizing a product backlog.` — สวมบทบาทเป็น Product Manager อาวุโสจัดลำดับความสำคัญของงาน
89. `Simulate a negotiation scenario between a vendor and procurement.` — จำลองสถานการณ์การเจรจาต่อรองระหว่างผู้ขายกับฝ่ายจัดซื้อ
90. `Act as an objective mediator helping resolve a workplace conflict.` — สวมบทบาทเป็นคนกลางไกล่เกลี่ยข้อพิพาทในที่ทำงานอย่างเป็นกลาง

## หมวด 10: Productivity & Daily Execution / งานเพิ่มประสิทธิภาพ (91–100) -> [EP1: Co-Worker]
91. `Suggest an optimized daily routine based on [schedule/goals].` — แนะนำตารางเวลาประจำวันที่มีประสิทธิภาพสูงสุดตาม [เป้าหมาย]
92. `Help me break down and prioritize this chaotic to-do list.` — ช่วยจัดระเบียบและจัดลำดับความสำคัญของรายการสิ่งที่ต้องทำที่ยุ่งเหยิง
