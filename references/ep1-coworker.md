# EP1 • CO-WORKER: คู่มือการทำงานร่วมกับไฟล์จริง

เป้าหมายสำคัญของ EP1 คือการยกระดับ AI จากการเป็นคู่สนทนาในกล่องแชท สู่การเป็น **"เพื่อนร่วมงานเต็มรูปแบบ"** ที่จัดการงานเอกสารและส่งต่องานจริงได้ทันที

---

## 1. หลักการทำงานกับไฟล์จริง (Real File Operations)

### ปัญหาของการทำงานแบบเดิม:
- ผู้ใช้ต้องคัดลอก (Copy) ข้อความยาว ๆ มาแปะในแชท
- เมื่อ AI ตอบกลับ ต้องคัดลอกผลลัพธ์กลับไปจัดหน้าใน Microsoft Word หรือ Excel เอง
- เสียเวลา เสียฟอร์แมต และเสี่ยงต่อข้อมูลตกหล่น

### แนวทางปฏิบัติของ EP1:
1. **Direct File Consumption:** ให้ AI อ่านไฟล์ต้นทางโดยตรง ไม่ว่าจะเป็น `.docx`, `.xlsx`, `.pptx`, `.csv` หรือ `.pdf`
2. **Direct File Generation:** ผลลัพธ์สุดท้ายต้องถูกเขียนลงไฟล์จริงในระบบไฟล์ พร้อมฟอร์แมต ตาราง หัวข้อ และการเน้นข้อความ
3. **Forward-Ready Quality:** ไฟล์ที่ออกมาต้องมีคุณภาพระดับมืออาชีพ สามารถแนบส่งอีเมลหรือนำเสนอในที่ประชุมได้ทันทีโดยไม่ต้องแก้ไขซ้ำ

---

## 2. โครงสร้างสถาปัตยกรรม Agent Supervisor

เพื่อควบคุมให้ผลงานของ AI สอดคล้องกับมาตรฐานบริษัท (Company Standards) สกิลนี้ใช้สถาปัตยกรรม **Agent Supervisor**:

```text
[User Request] 
      │
      ▼
[Worker Agent] ──(ผลิตแบบร่างเอกสาร)──> [Draft Document]
                                                │
                                                ▼
                                    [Supervisor Agent]
                                    - ตรวจสอบ Company Template
                                    - ตรวจสอบความถูกต้องของข้อมูล
                                    - ตรวจสอบ Tone of Voice
                                                │
                          ┌─────────────────────┴─────────────────────┐
                          ▼                                           ▼
                     [ผ่านเกณฑ์]                                 [ไม่ผ่านเกณฑ์]
                          │                                           │
                          ▼                                           ▼
             [Final Forwardable File]                   [ส่งกลับแก้ไขพร้อม Feedback]
```

## 3. รายการตรวจสอบก่อนส่งมอบงาน (EP1 Checklist)

- [ ] **ชนิดไฟล์ถูกต้อง:** เป็นไฟล์เอกสารจริงตามที่ผู้ใช้ต้องการ (.docx / .xlsx / .pptx)
- [ ] **การจัดรูปแบบสมบูรณ์:** มีการจัดลำดับหัวข้อ (Headings H1-H3), Bullet points และตารางที่อ่านง่าย
- [ ] **ไม่มี Placeholder หลงเหลือ:** ทุกจุดที่เป็น `[ใส่ข้อมูล]` หรือ `TODO` ต้องได้รับการเติมเต็มหรือระบุสถานะชัดเจน
- [ ] **พร้อมส่งต่อ:** บุคคลที่สามสามารถเปิดอ่านและเข้าใจบริบทได้ทันทีโดยไม่ต้องดูประวัติการแชท
